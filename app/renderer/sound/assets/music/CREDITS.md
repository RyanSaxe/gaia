# Music credits

Gaia's music is composed in code. Every note, velocity and swell is written in Python (the storybook chamber score
of Gaia's announcement film, rewritten for open-ended play), saved as MIDI, and played note by note through sampled
instruments. Nothing is generated by a model and nothing is a stock recording. The reverb is an impulse made in code
(band-shaped decaying noise).

The samples, all released under [Creative Commons 0 (CC0 1.0)](https://creativecommons.org/publicdomain/zero/1.0/):
free for any use, with no attribution required.

The instruments are played by [sfizz](https://github.com/sfztools/sfizz), the SFZ sample player (BSD 2-Clause). It
is a tool, and none of its code is in the audio.

`bed`, `melody`, `shimmer` and `minor` are four stems of one 32-bar piece that loop together; the `phrase-*` files
are short standalone pieces on the same theme. `manifest.json` gives each file's length, loudness and peak.
