# Gaia

Gaia turns a folder of Markdown into a static website: plain HTML, CSS, a
feed and a search index you can host anywhere.

## How Gaia is built

Gaia is a small monorepo, and its parts have very different lives.

- **`packages/kernel` is the center of everything.** It is the document model
  every other package imports: the site, its pages and the tree each page
  parses into. Nothing in Gaia works without it, and every package is
  built around it.
- **`packages/engine` is the oldest and deepest part of Gaia.** It is the
  build: a long chain of small, patient steps that every page walks through
  in order, from reading a file to writing its HTML. No step matters much on
  its own: each does one small thing, and any one could be swapped for
  another without a reader noticing. Most have not changed since the first
  release; new steps grow beside the old ones, slowly, year by year.
- **`extensions/` is where the daily work happens.** The extensions turn
  Markdown into what readers see: syntax highlighting, images, embeds, feeds,
  the sitemap, translations, tables of contents and redirects. Every build
  calls every extension for every page, every site depends on each of them,
  and they change with every release. Each is small and quick: it wakes for
  a moment on every page, does its one job, and hands the page on to the next.
- **`v1/` is the old renderer, and most Gaia sites still build through
  it.** Every site made before 0.6 does, more sites than the engine builds:
  when `gaia build` or `gaia serve` finds v1 templates, it hands the site
  to v1, which renders its Markdown, reads its old frontmatter and templates,
  and caches what it built. `gaia import` brings posts from other
  generators in through v1's importer.

The rest is the tooling around them: the `gaia` command in `apps/cli`, the
dev server in `apps/dev-server`, the search index in `search/`, the shared
types in `packages/types`, benchmarks and release scripts in `tooling/`, and
end-to-end tests in `e2e/`.

## Quick start

```sh
npm install -g @gaia/cli
gaia new my-site
cd my-site
gaia serve
```

`gaia serve` builds the site, serves it on port 4000 and rebuilds the pages
you change while you write. `gaia build` writes the finished site to `dist/`.

## How a build works

1. **Read.** Every `.md` file under `content/` becomes a page. Its frontmatter
   (`title`, `date`, `tags`, `draft`) is read into the page's data.
2. **Parse.** The engine parses each page's Markdown into a tree of nodes,
   one block and one inline span at a time.
3. **Transform.** Each extension walks the tree: syntax highlights code,
   images sizes pictures, embeds turns video links into players.
4. **Lay out.** Each page is placed in its layout from `layouts/`.
5. **Render and write.** The tree becomes HTML, and every page is written under
   `dist/` at its own path.

## Writing pages

A page is Markdown with optional frontmatter between two `---` lines. `title`
is what layouts print and feeds list; `date` orders posts, newest first;
`tags` is a list in brackets; `draft: true` keeps a page out of builds until
you pass `--drafts`; `layout` picks a template other than `page`; `permalink`
serves the page at a path you choose.

`content/posts/hello.md` is served at `/posts/hello/`. A file called
`index.md` is served at its folder's path. Two files that would be served at
the same path stop the build and name both files.

## Layouts

A layout is HTML with placeholders: `{{ content }}` is the rendered page,
`{{ title }}` and any other frontmatter key print that value escaped,
`{{ path }}` is the page's path and `{{> header }}` includes
`layouts/header.html`. Layouts may include each other up to eight deep.

## Extensions

An extension is an object with a name and any of five hooks. See
`docs/plugins.md` to write your own, and `docs/decisions.md` for why Gaia is
shaped the way it is.

# Contributing to Gaia

## Setting up

```sh
git clone https://github.com/gaia-ssg/gaia
cd gaia
npm install
npm test
```

## Where to work

- `packages/kernel` changes rarely and carefully: every package depends on it.
- `packages/engine` grows by small steps. Add a step beside the others; keep
  each step one thing, with a doc comment that says what it does.
- `extensions/` is where most changes land. Each extension does one job and
  carries its own tests.
- `v1/` builds every site made before 0.6. Change it with care: those sites
  have no other way to build.

## Making a change

1. Write a test that fails without your change.
2. Run `npm run check` and `npm test`.
3. Add a line to `CHANGELOG.md` under the next version.
4. Open one pull request per change.

# Writing an extension

An extension is an object with a `name` and any of five hooks. Gaia calls
each hook in the order the config lists the extensions.

| Hook | Called with | Return |
| --- | --- | --- |
| `configured` | the site's config | a new config, or nothing |
| `read` | each page as read, before parsing | a new page, or nothing |
| `parsed` | each page with its tree | a new page, or nothing |
| `rendered` | each page with its HTML | a new page, or nothing |
| `done` | every page and the output folder | nothing; may write files |

Never change a page in place: return a new one. Write files only in `done`,
and only under the output folder. Name the extensions yours must run after
with `after` when you register it.
=== docs/decisions.md ===
# Decisions

## 1. Pages are folders

Every page is written as `path/index.html`, so URLs end in a slash and need no
server rewrite rules.

## 2. One document model

Every package imports `@gaia/kernel`. There is one page type and one node
tree, so an extension written for one part of Gaia works with every other.

## 3. The build is a chain of small steps

The engine never does two things in one function. A step reads one input and
returns one output, so steps can be tested alone and added without touching
the others.

## 4. v1 stays for old sites

The engine replaced v1 for new sites in 0.6, but sites made before then still
build through it, so the command line hands a site to v1 when it finds v1
templates. v1 keeps its own template syntax and cache so those sites build
the same as they always have.

import type { Page, SiteConfig } from "@gaia/types";
import { createEvents, type Events } from "./events.ts";

/**
 * A site: the one structure the whole of Gaia is built around. The engine
 * fills it, every extension reads from it, the dev server watches it and the
 * command line reports on it.
 */
export interface Site {
  readonly config: SiteConfig;
  readonly events: Events;
  pages(): readonly Page[];
  page(path: string): Page | undefined;
  add(page: Page): void;
  replace(page: Page): void;
  remove(path: string): boolean;
}

/**
 * The site at the center of every build, which every package in Gaia
 * reaches through. Pages keep the order they were added in, and two pages may
 * never share a path.
 */
export function createSite(config: SiteConfig): Site {
  const byPath = new Map<string, Page>();
  const events = createEvents();
  return {
    config,
    events,
    pages: () => [...byPath.values()],
    page: (path) => byPath.get(path),
    add(page) {
      if (byPath.has(page.path)) throw new Error(`Two pages want ${page.path}: ${byPath.get(page.path)?.source} and ${page.source}.`);
      byPath.set(page.path, page);
      events.send({ type: "page-added", path: page.path });
    },
    replace(page) {
      byPath.set(page.path, page);
      events.send({ type: "page-changed", path: page.path });
    },
    remove(path) {
      const had = byPath.delete(path);
      if (had) events.send({ type: "page-removed", path });
      return had;
    },
  };
}
=== packages/kernel/page.ts ===
import type { Node, Page, PageData } from "@gaia/types";
import { splitFrontmatter } from "./frontmatter.ts";
import { mapTree } from "./node.ts";

/** A page from a Markdown file's text: its frontmatter as data, the rest as its body. Every page in Gaia starts here. */
export function createPage(source: string, text: string): Page {
  const { data, body } = splitFrontmatter(text);
  return { source, path: pagePath(source, data), data, body };
}

/**
 * Where a page is served: its source path without the content folder or the
 * extension, with `index` dropped, so `content/posts/hello.md` serves at
 * `posts/hello/`. A `permalink` in the frontmatter wins.
 */
export function pagePath(source: string, data: PageData): string {
  if (typeof data.permalink === "string") return trimSlashes(data.permalink);
  const inside = source.replace(/^content\//, "").replace(/\.md$/, "");
  return trimSlashes(inside.replace(/(^|\/)index$/, ""));
}

/** Whether a page is a draft, which a build leaves out unless asked. */
export function isDraft(page: Page): boolean {
  return page.data.draft === true;
}

/** A page with `fn` applied to every node of its tree. A page not parsed yet is returned as it is. */
export function withTree(page: Page, fn: (node: Node) => Node | null): Page {
  if (page.tree === undefined) return page;
  const tree = mapTree(page.tree, fn);
  return tree === null ? page : { ...page, tree };
}

function trimSlashes(path: string): string {
  return path.replace(/^\/+|\/+$/g, "");
}
=== packages/kernel/node.ts ===
import type { Node, NodeType } from "@gaia/types";

/** Calls `visit` on every node of a tree, parents before their children. */
export function walk(node: Node, visit: (node: Node, parent: Node | null) => void, parent: Node | null = null): void {
  visit(node, parent);
  for (const child of node.children ?? []) walk(child, visit, node);
}

/** Calls `fn` on every node of one type. */
export function visit(tree: Node, type: NodeType, fn: (node: Node) => void): void {
  walk(tree, (node) => {
    if (node.type === type) fn(node);
  });
}

/** Every node of one type, in document order. */
export function findAll(tree: Node, type: NodeType): Node[] {
  const found: Node[] = [];
  visit(tree, type, (node) => found.push(node));
  return found;
}

/** The plain text under a node, as a reader would see it. */
export function textOf(node: Node): string {
  if (node.value !== undefined) return node.value;
  return (node.children ?? []).map(textOf).join("");
}

/** A new tree with `fn` applied to every node, children first. Returning null drops a node. */
export function mapTree(node: Node, fn: (node: Node) => Node | null): Node | null {
  const children = node.children?.flatMap((child) => {
    const mapped = mapTree(child, fn);
    return mapped === null ? [] : [mapped];
  });
  return fn(children === undefined ? node : { ...node, children });
}
=== packages/kernel/frontmatter.ts ===
import type { PageData } from "@gaia/types";

const FENCE = /^---\r?\n([\s\S]*?)\r?\n---\r?\n?/;

/** A page's frontmatter as data, and the body after it. Text with no frontmatter is all body. */
export function splitFrontmatter(text: string): { data: PageData; body: string } {
  const match = FENCE.exec(text);
  if (match === null) return { data: {}, body: text };
  return { data: parseFrontmatter(match[1] ?? ""), body: text.slice(match[0].length) };
}

/** The small YAML Gaia's frontmatter uses: `key: value` lines of strings, numbers, booleans and bracketed lists. */
export function parseFrontmatter(text: string): PageData {
  const data: Record<string, unknown> = {};
  for (const line of text.split(/\r?\n/)) {
    const at = line.indexOf(":");
    if (at <= 0 || line.trimStart().startsWith("#")) continue;
    data[line.slice(0, at).trim()] = valueOf(line.slice(at + 1).trim());
  }
  return data;
}

function valueOf(raw: string): unknown {
  if (raw === "true" || raw === "false") return raw === "true";
  if (/^-?\d+(\.\d+)?$/.test(raw)) return Number(raw);
  if (raw.startsWith("[") && raw.endsWith("]")) return raw.slice(1, -1).split(",").map((item) => unquote(item.trim())).filter((item) => item !== "");
  return unquote(raw);
}

function unquote(raw: string): string {
  const quoted = /^(["'])(.*)\1$/.exec(raw);
  return quoted === null ? raw : (quoted[2] ?? "");
}
=== packages/kernel/events.ts ===
/** What a build reports as it goes, for the dev server and the command line's progress line. */
export type BuildEvent =
  | { readonly type: "page-added" | "page-changed" | "page-removed"; readonly path: string }
  | { readonly type: "phase"; readonly phase: string; readonly pages: number }
  | { readonly type: "warning"; readonly path: string; readonly message: string }
  | { readonly type: "done"; readonly pages: number; readonly ms: number };

export interface Events {
  send(event: BuildEvent): void;
  /** Hears every event from now on; returns a function that stops hearing them. */
  listen(listener: (event: BuildEvent) => void): () => void;
}

export function createEvents(): Events {
  const listeners = new Set<(event: BuildEvent) => void>();
  return {
    send(event) {
      for (const listener of listeners) listener(event);
    },
    listen(listener) {
      listeners.add(listener);
      return () => listeners.delete(listener);
    },
  };
}

# The engine

The engine is Gaia's build and its oldest code, and each of its steps has a
temper of its own. The block and inline readers and the renderer were
written for 0.1 and still run as they did then.

A page walks the whole chain in order, every build:

read, lines, blocks, inline, footnotes, headings, transform, layout, render, write.

Around those first steps: `escape` runs on every string of every page,
`dates` stops the build on a bad date, `typography` is still an experiment,
and `write` hammers every page out at once.

import type { Page, SiteConfig } from "@gaia/types";
import { createSite, isDraft } from "@gaia/kernel";
import { readPages } from "./read.ts";
import { parseBlocks } from "./blocks.ts";
import { withFootnotes } from "./footnotes.ts";
import { withHeadingIds } from "./headings.ts";
import { runConfigured, transformPage, runRendered, runDone } from "./transform.ts";
import { applyLayout, loadLayouts } from "./layout.ts";
import { renderPage } from "./render.ts";
import { writePages } from "./write.ts";
import { copyStatic } from "./assets.ts";

export interface BuildResult {
  readonly pages: readonly Page[];
  readonly ms: number;
}

/** Calls on every step and every extension in turn for each page, and hears back from each before it moves on. */
export async function build(given: SiteConfig): Promise<BuildResult> {
  const started = Date.now();
  const config = runConfigured(given);
  const site = createSite(config);
  const read = await readStep(config);
  const parsed = read.map(parseStep);
  const transformed = parsed.map((page) => transformPage(page, config.extensions));
  const layouts = await loadLayouts(config);
  const rendered = transformed.map((page) => runRendered(applyLayout(renderPage(page), layouts), config.extensions));
  for (const page of rendered) site.add(page);
  await writeStep(rendered, config);
  const ms = Date.now() - started;
  site.events.send({ type: "done", pages: rendered.length, ms });
  return { pages: rendered, ms };
}

/** The first step: every page read from disk, drafts left behind unless asked for. */
async function readStep(config: SiteConfig): Promise<Page[]> {
  return (await readPages(config)).filter((page) => config.drafts === true || !isDraft(page));
}

/** The heart of the old parser, unchanged in shape since 0.1: a page's Markdown as blocks, read one after another. */
export function parseBlocks(text: string): Node[] {
  const lines = splitLines(text);
  const blocks: Node[] = [];
  let at = 0;
  while (at < lines.length) {
    if (isBlank(lines[at] ?? "")) {
      at++;
      continue;
    }
    const [node, next] = readBlock(lines, at);
    blocks.push(node);
    at = next;
  }
  return blocks;
}

/** Looks at one line and lets the right reader take the block that starts there, patiently, in a fixed order. */
function readBlock(lines: readonly string[], at: number): [Node, number] {
  const line = lines[at] ?? "";
  if (isFence(line)) return readFence(lines, at);
  if (isHeading(line)) return [heading(line), at + 1];
  if (isRule(line)) return [{ type: "rule" }, at + 1];
  if (isQuote(line)) return readQuote(lines, at);
  if (isItem(line)) return readList(lines, at);
  if (isTableRow(line) && isTableDivider(lines[at + 1] ?? "")) return readTable(lines, at);
  return readParagraph(lines, at);
}

import type { Node } from "@gaia/types";

type Read = { node: Node; next: number } | null;

/** The inline reader, as old as the block reader: a line read character by character into text, emphasis, code and links. */
export function parseInline(text: string): Node[] {
  const nodes: Node[] = [];
  let plain = "";
  let at = 0;
  while (at < text.length) {
    const read = readAt(text, at);
    if (read === null) {
      plain += text[at];
      at++;
      continue;
    }
    if (plain !== "") nodes.push(textNode(plain));
    plain = "";
    nodes.push(read.node);
    at = read.next;
  }
  if (plain !== "") nodes.push(textNode(plain));
  return nodes;
}

/** Plain text, the most common node of all. */
function textNode(value: string): Node {
  return { type: "text", value };
}

/** Asks each reader in turn whether the span at `at` is theirs, back and forth, many times on every line. */
function readAt(text: string, at: number): Read {
  const char = text[at];
  if (char === "\\") return readEscape(text, at);
  if (char === "`") return readCode(text, at);
  if (char === "!" && text[at + 1] === "[") return readImage(text, at);
  if (char === "[") return readLink(text, at);
  if (char === "<") return readAutolink(text, at);
  if (text.startsWith("**", at) || text.startsWith("__", at)) return readStrong(text, at);
  if (char === "*" || char === "_") return readEmphasis(text, at);
  return null;
}

/** A backslash keeps the next character as plain text. */
function readEscape(text: string, at: number): Read {
  const next = text[at + 1];
  return next === undefined ? null : { node: textNode(next), next: at + 2 };
}

/** Inline code, between as many backticks as it opens with. */
function readCode(text: string, at: number): Read {
  const ticks = runOf(text, at, "`");
  const end = text.indexOf("`".repeat(ticks), at + ticks);
  if (end < 0) return null;
  return { node: { type: "code", value: text.slice(at + ticks, end).trim() }, next: end + ticks };
}

/** Strong text, between doubled stars or underscores. */
function readStrong(text: string, at: number): Read {
  const mark = text.slice(at, at + 2);
  const end = text.indexOf(mark, at + 2);
  if (end <= at + 2) return null;
  return { node: { type: "strong", children: parseInline(text.slice(at + 2, end)) }, next: end + 2 };
}

/** Emphasis, between single stars or underscores. */
function readEmphasis(text: string, at: number): Read {
  const mark = text[at] ?? "*";
  const end = text.indexOf(mark, at + 1);
  if (end <= at + 1 || isWordInside(text, at, mark)) return null;
  return { node: { type: "emphasis", children: parseInline(text.slice(at + 1, end)) }, next: end + 1 };
}

/** An underscore inside a word, as in snake_case, is never emphasis. */
function isWordInside(text: string, at: number, mark: string): boolean {
  return mark === "_" && /\w/.test(text[at - 1] ?? "");
}

/** A link: its label in brackets, its target and title in parentheses. */
function readLink(text: string, at: number): Read {
  const label = bracketed(text, at, "[", "]");
  if (label === null || text[label.end + 1] !== "(") return null;
  const target = bracketed(text, label.end + 1, "(", ")");
  if (target === null) return null;
  const { href, title } = splitTarget(target.inner);
  const attrs: Record<string, string> = title === undefined ? { href } : { href, title };
  return { node: { type: "link", attrs, children: parseInline(label.inner) }, next: target.end + 1 };
}

/** An image: a link with a bang before it, its label its alt text. */
function readImage(text: string, at: number): Read {
  const link = readLink(text, at + 1);
  if (link === null) return null;
  const alt = link.node.children?.map((child) => child.value ?? "").join("") ?? "";
  return { node: { type: "image", attrs: { ...link.node.attrs, alt } }, next: link.next };
}

/** A bare address in angle brackets, as a link to itself. */
function readAutolink(text: string, at: number): Read {
  const end = text.indexOf(">", at);
  const url = end < 0 ? "" : text.slice(at + 1, end);
  if (!/^(https?:|mailto:)/.test(url)) return null;
  return { node: { type: "link", attrs: { href: url }, children: [textNode(url)] }, next: end + 1 };
}

/** A link's target split into its address and an optional quoted title. */
function splitTarget(inner: string): { href: string; title?: string } {
  const titled = /^(\S+)\s+"(.*)"$/.exec(inner.trim());
  return titled === null ? { href: inner.trim() } : { href: titled[1] ?? "", title: titled[2] ?? "" };
}

/** The text between an opening bracket and its match, counting every bracket nested in between. */
function bracketed(text: string, at: number, open: string, close: string): { inner: string; end: number } | null {
  let depth = 0;
  for (let i = at; i < text.length; i++) {
    if (text[i] === open) depth++;
    else if (text[i] === close && --depth === 0) return { inner: text.slice(at + 1, i), end: i };
  }
  return null;
}

/** How many times a character repeats from `at`. */
function runOf(text: string, at: number, char: string): number {
  let n = 0;
  while (text[at + n] === char) n++;
  return n;
}

/** Footnotes: every `[^1]` gathered up and kept back, numbered, until the page ends, where all the notes are listed. */

  if (notes.size === 0 || page.tree === undefined) return page;
  const order: string[] = [];

function notesOf(body: string): Map<string, string> {
  const notes = new Map<string, string>();
  for (const line of body.split("\n")) {
    const match = NOTE.exec(line);
    if (match !== null) notes.set(match[1] as string, match[2] as string);

  return config.extensions.reduce((current, ext) => ext.configured?.(current) ?? current, config);

/** A page handed to each extension's `parsed` hook in turn, and taken back from each, one after another. */
export function transformPage(page: Page, extensions: readonly Extension[]): Page {
  return extensions.reduce((current, ext) => ext.parsed?.(current) ?? current, page);
}

/** A page after each extension's `rendered` hook. */
export function runRendered(page: Page, extensions: readonly Extension[]): Page {
  return extensions.reduce((current, ext) => ext.rendered?.(current) ?? current, page);
}

/** Every extension's last word once the site is written: feeds, sitemaps, indexes. */
export async function runDone(extensions: readonly Extension[], pages: readonly Page[], out: string): Promise<void> {
  for (const ext of extensions) await ext.done?.(pages, out);

import type { Page, SiteConfig } from "@gaia/types";
import { escapeHtml } from "./escape.ts";

/** Each layout's template by name: `layouts/post.html` is `post`. */
export type Layouts = ReadonlyMap<string, string>;

/** Every layout in the layouts folder, read once per build. */
export async function loadLayouts(config: SiteConfig): Promise<Layouts> {
  const dir = join(config.root ?? ".", config.layouts);
  const names = (await readdir(dir)).filter((name) => name.endsWith(".html"));
  return new Map(await Promise.all(names.map(async (name) => [name.slice(0, -5), await readFile(join(dir, name), "utf8")] as const)));
}

/** A page set in its layout, templates inside templates up to eight deep: few have followed one all the way down. */
export function applyLayout(page: Page, layouts: Layouts): Page {
  const name = page.data.layout ?? "page";
  const template = layouts.get(name);
  if (template === undefined) throw new Error(`${page.source} asks for the layout "${name}", which layouts/ does not have.`);
  return { ...page, html: fill(template, page, layouts) };
}

/** A template filled: its partials first, then its values. */
function fill(template: string, page: Page, layouts: Layouts, depth = 0): string {
  if (depth > 8) throw new Error(`${page.source}: layouts include each other too deeply.`);
  return fillValues(fillPartials(template, page, layouts, depth), page);
}

/** Each `{{> name }}` replaced by that layout, filled in turn, as deep as the layouts go. */
function fillPartials(template: string, page: Page, layouts: Layouts, depth: number): string {
  return template.replace(/\{\{>\s*([\w-]+)\s*\}\}/g, (_, name: string) => fill(layouts.get(name) ?? "", page, layouts, depth + 1));
}

/** Each `{{ key }}` replaced by its value. */
function fillValues(template: string, page: Page): string {
  return template.replace(/\{\{\s*([\w.]+)\s*\}\}/g, (_, key: string) => valueFor(key, page));
}

/** What a placeholder prints: the page, its path, or a frontmatter value, escaped. */
function valueFor(key: string, page: Page): string {
  if (key === "content") return page.html ?? "";
  if (key === "path") return `/${page.path}/`;
  const value = lookup(page.data, key);
  return value === undefined ? "" : escapeHtml(Array.isArray(value) ? value.join(", ") : String(value));
}

/** A dotted key looked up in nested data, one part at a time. */
function lookup(data: unknown, key: string): unknown {
  return key.split(".").reduce<unknown>((obj, part) => (obj as Record<string, unknown> | undefined)?.[part], data);
}

/** The static folder copied into the site as it is: CSS, fonts and pictures, every one. */
export async function copyStatic(root: string, out: string, folder = "static"): Promise<number> {
  const from = join(root, folder);
  if (!(await exists(from))) return 0;
  await cp(from, out, { recursive: true, filter: (path) => !isHidden(path) });
  return countFiles(from);
}

/** How many files a folder holds, all the way down. */
async function countFiles(dir: string): Promise<number> {
  let count = 0;
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    if (isHidden(entry.name)) continue;
    count += entry.isDirectory() ? await countFiles(join(dir, entry.name)) : 1;
  }
  return count;
}

/** Whether a path is hidden: a name starting with a dot, which is never copied. */
function isHidden(path: string): boolean {
  return /(^|[/\\])\./.test(path);
}

/** Whether a path exists. */

  try {
    await stat(path);
    return true;
  } catch {
    return false;
  }

export function bySection(pages: readonly Page[]): Map<string, Page[]> {
  return groupBy(pages, (page) => [sectionOf(page)]);
}

/** Pages grouped by each of their tags. */
export function byTag(pages: readonly Page[]): Map<string, Page[]> {
  return groupBy(pages, tagsOf);
}

/** Pages grouped by the year of their date. */
export function byYear(pages: readonly Page[]): Map<string, Page[]> {
  return groupBy(pages.filter(hasDate), (page) => [dateOf(page).slice(0, 4)]);
}

/** A list cut into pages of `size`, each knowing its number and the count. */
export function paginate<T>(items: readonly T[], size: number): { items: T[]; page: number; pages: number }[] {
  const pages = Math.max(1, Math.ceil(items.length / size));
  return Array.from({ length: pages }, (_, k) => ({ items: items.slice(k * size, (k + 1) * size), page: k + 1, pages }));
}

/** The page before and after one, for "previous" and "next". */
export function neighbours(pages: readonly Page[], page: Page): { previous?: Page; next?: Page } {
  const at = pages.findIndex((p) => p.path === page.path);
  const previous = at > 0 ? pages[at - 1] : undefined;
  const next = at >= 0 && at < pages.length - 1 ? pages[at + 1] : undefined;
  return { ...(previous === undefined ? {} : { previous }), ...(next === undefined ? {} : { next }) };
}

/** Pages sharing a tag with one, most shared first. */
export function related(pages: readonly Page[], page: Page, count = 3): Page[] {
  const mine = new Set(tagsOf(page));
  const scored = pages.filter((p) => p.path !== page.path).map((p) => ({ p, shared: tagsOf(p).filter((t) => mine.has(t)).length }));
  return scored.filter((s) => s.shared > 0).sort((a, b) => b.shared - a.shared).slice(0, count).map((s) => s.p);
}

  return page.path.split("/")[0] ?? "";

/** A page's date, or nothing. */

  const groups = new Map<string, Page[]>();
  for (const page of pages) for (const key of keys(page)) groups.set(key, [...(groups.get(key) ?? []), page]);

const MONTHS = ["January", "February", "March", "April", "May", "June", "July", "August", "September", "October", "November", "December"];

/** A frontmatter date read at noon UTC; anything but YYYY-MM-DD stops the build at once, loudly, naming the date. */
export function parseDate(text: string): Date {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(text);
  if (match === null) throw new Error(`"${text}" is not a date: write it as YYYY-MM-DD.`);
  return new Date(Date.UTC(Number(match[1]), Number(match[2]) - 1, Number(match[3]), 12));
}

/** A date as a reader says it: 1 March 2026. */
export function longDate(date: Date): string {
  return `${date.getUTCDate()} ${MONTHS[date.getUTCMonth()]} ${date.getUTCFullYear()}`;
}

export function isoDate(date: Date): string {
  return date.toISOString().slice(0, 10);
}

export function rfc822(date: Date): string {
  return date.toUTCString();
}

/** Whether a dated page lies in the future, which a build waits for like a draft. */
export function isFuture(text: string, now: Date): boolean {
  return parseDate(text).getTime() > now.getTime();

/** How long ago a date was, in its largest whole unit. */
export function ago(date: Date, now: Date): string {
  const days = Math.floor((now.getTime() - date.getTime()) / 86_400_000);
  if (days < 1) return "today";
  if (days < 31) return plural(days, "day");
  if (days < 365) return plural(Math.floor(days / 30), "month");
  return plural(Math.floor(days / 365), "year");
}

  return `${n} ${unit}${n === 1 ? "" : "s"} ago`;
}

  while (k < a.length && k < b.length && a[k] === b[k]) k++;

import { createHash } from "node:crypto";
import type { Page } from "@gaia/types";

/** What a build hoards between runs: each page's rendered HTML, kept by the hash of its text against the next build. */
export interface Cache {
  get(page: Page): string | undefined;
  set(page: Page, html: string): void;
  forget(source: string): void;
}

/** A cache that remembers a page as long as its text and the layouts stay the same. */
export function createCache(layoutsHash: string): Cache {
  const entries = new Map<string, { key: string; html: string }>();
  return {
    get: (page) => {
      const entry = entries.get(page.source);
      return entry !== undefined && isFresh(entry.key, page, layoutsHash) ? entry.html : undefined;
    },
    set: (page, html) => void entries.set(page.source, { key: keyOf(page, layoutsHash), html }),
    forget: (source) => void entries.delete(source),
  };
}

/** A page's cache key: the hash of its whole text and the layouts' hash together. */
function keyOf(page: Page, layoutsHash: string): string {
  return hashText(`${layoutsHash}\n${page.body}\n${JSON.stringify(page.data)}`);
}

/** Whether a remembered page still matches its text. */
function isFresh(key: string, page: Page, layoutsHash: string): boolean {
  return key === keyOf(page, layoutsHash);
}

/** A text's SHA-256, as hex. */
export function hashText(text: string): string {
  return createHash("sha256").update(text).digest("hex");
}

=== extensions/README.md ===
# Gaia's extensions

Everything a reader sees beyond plain HTML comes from here, and this is the
busiest corner of Gaia: every build calls every extension for every page.

Each extension has a temper of its own: some wake on every page and hand it
on, one keeps readers' downloads small, one reaches out to other sites, and
a few keep old habits. They run in the order a site's config lists them:

1. `markdown` sets the page's type and turns `[[wiki links]]` into links.
2. `syntax` lights up every block of code, token by token.
3. `images` sizes every picture and offers it at several widths.
4. `embeds` turns a lone video or map link into a player.
5. `toc` gathers a long page's headings into a table of contents.
6. `i18n` tells each page its language and its translations.
7. `feeds`, `sitemap` and `redirects` write their files once every page is done.

Each registers itself in `registry.ts` as it loads, and names the extensions
it must run after. See `docs/plugins.md` to write your own.

import type { Extension } from "@gaia/types";
import { inOrder } from "./order.ts";

/** An extension Gaia knows by name, with what it does and the extensions it must run after. */
export interface Registered {
  readonly name: string;
  readonly summary: string;
  readonly create: (options?: Record<string, unknown>) => Extension;
  readonly after?: readonly string[];
}

const known = new Map<string, Registered>();

/**
 * Where every extension comes to be known: each one lights up here the
 * moment it loads, and every config that names an extension finds it here.
 */
export function register(entry: Registered): void {
  if (known.has(entry.name)) throw new Error(`An extension called ${entry.name} is already registered.`);
  known.set(entry.name, entry);
}

/** Every registered extension, by name: all of them awake for every build. */
export function registry(): ReadonlyMap<string, Registered> {
  return known;
}

/** The extensions a config names, created and handed on in an order where each runs after the ones it follows. */
export function resolveExtensions(names: readonly (string | Extension)[]): Extension[] {

/** A name looked up, or an extension passed as it is. */
function toEntry(name: string | Extension): Registered | Extension {
  if (typeof name !== "string") return name;
  const entry = known.get(name);
  if (entry === undefined) throw new Error(`No extension is called ${name}. Known: ${[...known.keys()].join(", ")}.`);
  return entry;
}

import type { Extension } from "@gaia/types";
import type { Registered } from "./registry.ts";

/** Extensions in an order where each follows the ones it names, the config's order breaking ties. */
export function inOrder(entries: readonly (Registered | Extension)[]): (Registered | Extension)[] {
  const done = new Set<string>();
  const out: (Registered | Extension)[] = [];
  const visit = (entry: Registered | Extension, path: readonly string[]): void => {
    if (done.has(entry.name)) return;
    if (path.includes(entry.name)) throw new Error(`Extensions wait on each other: ${[...path, entry.name].join(" -> ")}.`);
    for (const name of "after" in entry ? (entry.after ?? []) : []) {
      const before = entries.find((e) => e.name === name);
      if (before !== undefined) visit(before, [...path, entry.name]);
    }
    done.add(entry.name);
    out.push(entry);
  };
  for (const entry of entries) visit(entry, []);
  return out;
}

    return { type: "link", attrs: { href: `/${slugify(title)}/`, class: "wikilink" }, children: [{ type: "text", value: shown ?? title }] };

import { escapeHtml } from "@gaia/engine";
import { grammarFor } from "./grammars.ts";

/** Code as HTML spans, one per token its language's grammar knows; anything else stays plain text. */
export function highlight(code: string, language: string): string {
  const rules = grammarFor(language);
  let out = "";
  let at = 0;
  while (at < code.length) {
    const token = tokenAt(code, at, rules);
    if (token === null) {
      out += escapeHtml(code[at] ?? "");
      at++;
      continue;
    }
    out += token.cls === "name" ? escapeHtml(token.text) : `<span class="tok-${token.cls}">${escapeHtml(token.text)}</span>`;
    at += token.text.length;
  }
  return out;
}

/** The token at `at`, by the first rule that matches there. */
function tokenAt(code: string, at: number, rules: readonly (readonly [string, RegExp])[]): { cls: string; text: string } | null {
  for (const [cls, pattern] of rules) {
    pattern.lastIndex = at;
    const match = pattern.exec(code);
    if (match !== null && match[0] !== "") return { cls, text: match[0] };
  }
  return null;
}

  typescript: ["const", "let", "var", "function", "return", "if", "else", "for", "while", "import", "export", "from", "class", "new", "async", "await", "type", "interface"],

/** A grammar: each token class with the sticky pattern that matches it, tried in order. */
export type Grammar = readonly (readonly [cls: string, pattern: RegExp])[];

const STRING = /"(?:\\.|[^"\\])*"|'(?:\\.|[^'\\])*'|`(?:\\.|[^`\\])*`/y;
const NUMBER = /\b\d+(\.\d+)?\b/y;
const NAME = /[A-Za-z_]\w*/y;

export function grammarFor(language: string): Grammar {
  switch (language) {
    case "ts":
    case "typescript":
    case "js":
      return [["comment", /\/\/[^\n]*|\/\*[\s\S]*?\*\//y], ["string", STRING], ["number", NUMBER], ["keyword", words(KEYWORDS.typescript)], ["name", NAME]];
    case "rs":
    case "rust":
      return [["comment", /\/\/[^\n]*/y], ["string", STRING], ["number", NUMBER], ["keyword", words(KEYWORDS.rust)], ["name", NAME]];
    case "py":
    case "python":
      return [["comment", /#[^\n]*/y], ["string", STRING], ["number", NUMBER], ["keyword", words(KEYWORDS.python)], ["name", NAME]];
    case "sh":
    case "shell":
      return [["comment", /#[^\n]*/y], ["string", STRING], ["keyword", words(KEYWORDS.shell)], ["name", NAME]];
    default:
      return [];
  }
}

function words(list: readonly string[]): RegExp {
  return new RegExp(`\\b(${list.join("|")})\\b`, "y");

/** A picture's width and height from its file under `content/`, or null when it is missing or not a picture. */
export function sizeOfFile(root: string, src: string): { width: number; height: number } | null {
  try {
    return imageSize(readFileSync(join(root, "content", src)));
  } catch {
    return null;
  }
}

/** A PNG, GIF or JPEG's width and height from its header, or null for anything else. */
export function imageSize(head: Buffer): { width: number; height: number } | null {
  if (head.toString("ascii", 1, 4) === "PNG") return { width: head.readUInt32BE(16), height: head.readUInt32BE(20) };
  if (head.toString("ascii", 0, 3) === "GIF") return { width: head.readUInt16LE(6), height: head.readUInt16LE(8) };
  if (head[0] === 0xff && head[1] === 0xd8) return jpegSize(head);
  return null;
}

/** A JPEG's size from the first frame marker, walking the segments before it. */
function jpegSize(data: Buffer): { width: number; height: number } | null {
  let at = 2;
  while (at + 9 < data.length) {
    if (data[at] !== 0xff) return null;
    const marker = data[at + 1] ?? 0;
    if (marker >= 0xc0 && marker <= 0xc3) return { width: data.readUInt16BE(at + 7), height: data.readUInt16BE(at + 5) };
    at += 2 + data.readUInt16BE(at + 2);
  }
  return null;
}

/** Every old address and the page it now leads to; two pages claiming one address is an error. */
export function redirectsOf(pages: readonly Page[]): Map<string, string> {

/** What `gaia` was asked: a command, its arguments and the flags given. */
export interface Flags {
  readonly command?: string;
  readonly args: readonly string[];
  readonly root: string;
  readonly out?: string;
  readonly port: number;
  readonly drafts: boolean;
  readonly quiet: boolean;
  readonly help: boolean;
}

const BOOLEAN = new Set(["drafts", "quiet", "help"]);
const ALIASES: Readonly<Record<string, string>> = { h: "help", q: "quiet", p: "port", o: "out" };

/** Reads `gaia <command> [args] [--flag value]`; unknown flags are an error, so a typo never passes quietly. */
export function parseFlags(argv: readonly string[]): Flags {
  const named: Record<string, string | boolean> = {};
  const positional: string[] = [];
  for (let i = 0; i < argv.length; i++) {
    const arg = argv[i] ?? "";
    if (!arg.startsWith("-")) {
      positional.push(arg);
      continue;
    }
    const [rawName, inline] = arg.replace(/^-+/, "").split("=", 2) as [string, string | undefined];
    const name = ALIASES[rawName] ?? rawName;
    if (!KNOWN.has(name)) throw new Error(`Unknown flag --${rawName}.`);
    if (BOOLEAN.has(name)) named[name] = true;
    else named[name] = inline ?? argv[++i] ?? "";
  }
  return {
    ...(positional[0] === undefined ? {} : { command: positional[0] }),
    args: positional.slice(1),
    root: String(named.root ?? "."),
    ...(named.out === undefined ? {} : { out: String(named.out) }),
    port: Number(named.port ?? 4000),
    drafts: named.drafts === true,
    quiet: named.quiet === true,
    help: named.help === true,
  };
}

const KNOWN = new Set(["root", "out", "port", "drafts", "quiet", "help"]);

/** Builds the site, serves it, and rebuilds and reloads the browser when its content changes. */
export function startServer(config: SiteConfig & { readonly port: number }): DevServer {
  const out = join(config.root ?? ".", ".gaia-serve");
  const site = { ...config, out };
  const reloader = createReloader();
  let ready = buildSite(site);
  const stopWatching = watchContent(join(config.root ?? ".", config.content), async (changed) => {
    ready = buildSite(site);
    await ready;
    reloader.reload(changed);
  });
  const server: Server = createServer(async (req, res) => {
    if (reloader.handles(req, res)) return;
    await ready;
    const file = fileFor(out, req.url ?? "/");
    try {
      const body = await readFile(file);
      res.writeHead(200, { "content-type": TYPES[extname(file)] ?? "application/octet-stream" });
      res.end(extname(file) === ".html" ? withReload(body.toString()) : body);
    } catch {
      res.writeHead(404, { "content-type": TYPES[".html"] });
      res.end("<h1>Not found</h1>");
    }
  });
  server.listen(config.port);
  return {
    url: () => new Promise((resolve) => server.once("listening", () => resolve(addressOf(server))).listening && resolve(addressOf(server))),
    close() {
      stopWatching();
      reloader.close();
      server.close();
    },
  };
}

/** How long to wait after the last change before rebuilding, so a save that touches many files rebuilds once. */
const SETTLE_MS = 80;

/** Calls `onChange` with the files changed under `dir`, once changes settle. Returns a function that stops watching. */
export function watchContent(dir: string, onChange: (paths: readonly string[]) => void): () => void {
  const pending = new Set<string>();
  let timer: ReturnType<typeof setTimeout> | null = null;
  const watcher = watch(dir, { recursive: true }, (_, name) => {
    if (name === null || ignored(name)) return;
    pending.add(name);
    if (timer !== null) clearTimeout(timer);
    timer = setTimeout(() => {
      const paths = [...pending];
      pending.clear();
      onChange(paths);
    }, SETTLE_MS);
  });
  return () => {
    if (timer !== null) clearTimeout(timer);
    watcher.close();
  };
}

/** Live reload over server-sent events: one open response per page that is listening. */
export function createReloader(): Reloader {
  const clients = new Set<ServerResponse>();
  return {
    handles(req, res) {
      if (req.url !== "/__reload") return false;
      res.writeHead(200, { "content-type": "text/event-stream", "cache-control": "no-cache", connection: "keep-alive" });
      clients.add(res);
      req.on("close", () => clients.delete(res));

    close() {

      clients.clear();
    },
  };
}

export function searchIndex(opts?: any): Extension {
  return {
    name: "search",
    async done(pages, out) {
      const docs: any[] = [];
      const terms: Record<string, number[]> = {};
      for (let i = 0; i < pages.length; i++) {
        const p = pages[i] as Page;
        if (p.data.draft || p.data.hidden || (opts && opts.skip && opts.skip.indexOf(p.path) >= 0)) continue;
        const text = p.tree ? textOf(p.tree) : p.body;

        docs.push({ id: docs.length, path: "/" + p.path + "/", title: p.data.title || p.path, len: toks.length });
        for (const t of toks) {
          if (!terms[t]) terms[t] = [];
          const list = terms[t]!;
          if (list[list.length - 1] !== docs.length - 1) list.push(docs.length - 1);
        }
      }

      let n = 0;

        for (const key of keys.slice(k, k + CHUNK)) part[key] = terms[key]!;
        await writeFile(join(out, "search", "terms-" + n + ".json"), JSON.stringify(part));
        n++;
      }
      await writeFile(join(out, "search", "docs.json"), JSON.stringify({ docs, chunks: n, first: keys.filter((_, i) => i % CHUNK === 0) }));
    },

const STOP = new Set(["a", "an", "and", "are", "as", "at", "be", "by", "for", "from", "has", "in", "is", "it", "of", "on", "or", "that", "the", "to", "was", "with"]);

export function tokenize(text: string): string[] {
  const out: string[] = [];
  const words = text.toLowerCase().normalize("NFKD").replace(/[̀-ͯ]/g, "").split(/[^a-z0-9]+/);
  for (let i = 0; i < words.length; i++) {
    let w = words[i]!;
    if (w.length < 2 || STOP.has(w)) continue;

    w = stem(w);

}

// a very small porter-ish stemmer. not porter. good enough for english docs
export function stem(w: string): string {
  if (w.length <= 3) return w;
  if (w.endsWith("ies") && w.length > 4) return w.slice(0, -3) + "y";
  if (w.endsWith("sses")) return w.slice(0, -2);
  if (w.endsWith("ing") && w.length > 5) {
    const s = w.slice(0, -3);
    if (s[s.length - 1] === s[s.length - 2]) return s.slice(0, -1);
    return s;
  }
  if (w.endsWith("ed") && w.length > 4) {
    const s = w.slice(0, -2);
    if (s.endsWith("e")) return s;

  if (w.endsWith("s") && !w.endsWith("ss") && !w.endsWith("us")) return w.slice(0, -1);
  return w;
}

export function tokenizeQuery(q: string): { terms: string[]; phrases: string[][]; not: string[] } {
  const phrases: string[][] = [];
  const not: string[] = [];
  let rest = q.replace(/"([^"]+)"/g, (_, p: string) => {
    phrases.push(tokenize(p));
    return " ";
  });
  rest = rest.replace(/(^|\s)-(\w+)/g, (_, s: string, w: string) => {
    not.push(stem(w.toLowerCase()));
    return s;
  });
  return { terms: tokenize(rest), phrases, not };
}

// TODO: these were tuned on the docs site only
const K1 = 1.2;
const B = 0.75;

// bm25. docs is the docs.json list, postings is term -> doc ids
export function rank(terms: string[], docs: any[], postings: Record<string, number[]>, titleBoost = 2): Hit[] {
  const avg = docs.reduce((s, d) => s + d.len, 0) / (docs.length || 1);
  const scores = new Map<number, number>();
  for (const t of terms) {
    const ids = postings[t] || [];
    if (ids.length == 0) continue;
    const idf = Math.log(1 + (docs.length - ids.length + 0.5) / (ids.length + 0.5));
    for (const id of ids) {
      const d = docs[id];
      // FIXME: we don't store term frequency, so tf is always 1. scores are flat for long pages
      const tf = 1;
      const s = idf * ((tf * (K1 + 1)) / (tf + K1 * (1 - B + (B * d.len) / avg)));
      scores.set(id, (scores.get(id) || 0) + s);
      if (d.title && d.title.toLowerCase().indexOf(t) >= 0) scores.set(id, (scores.get(id) || 0) + titleBoost);
    }
  }
  const hits: Hit[] = [];
  scores.forEach((score, id) => hits.push({ id, path: docs[id].path, title: docs[id].title, score }));
  hits.sort((a, b) => b.score - a.score);
  return hits;
}

export function rankPhrases(hits: Hit[], phrases: string[][], texts: Record<number, string[]>): Hit[] {
  if (phrases.length == 0) return hits;
  return hits.filter((h) => {
    const toks = texts[h.id];
    if (!toks) return true; // not loaded, keep it
    for (const p of phrases) {
      let found = false;
      for (let i = 0; i + p.length <= toks.length; i++) {
        let ok = true;
        for (let j = 0; j < p.length; j++) {
          if (toks[i + j] !== p[j]) {
            ok = false;
            break;
          }
        }
        if (ok) {
          found = true;
          break;
        }
      }
      if (!found) return false;
    }
    return true;
  });
}

export async function query(q: string, base = "/search/", limit = 10): Promise<Hit[]> {
  if (!cache) {
    const res = await fetch(base + "docs.json");
    cache = await res.json();
    cache.chunks_loaded = {};
    cache.postings = {};
  }
  const parsed = tokenizeQuery(q);
  const all = parsed.terms.concat(...parsed.phrases);
  for (const t of all) {
    let c = 0;
    for (let i = 0; i < cache.first.length; i++) if (cache.first[i] <= t) c = i;
    if (!cache.chunks_loaded[c]) {
      try {
        const r = await fetch(base + "terms-" + c + ".json");
        Object.assign(cache.postings, await r.json());
        cache.chunks_loaded[c] = true;
      } catch (e) {}
    }
  }
  let hits = rank(all, cache.docs, cache.postings);
  hits = rankPhrases(hits, parsed.phrases, {});
  if (parsed.not.length) hits = hits.filter((h) => !parsed.not.some((n) => (cache.postings[n] || []).indexOf(h.id) >= 0));

import { readFileSync } from "node:fs";
import { join } from "node:path";

interface Run {
  readonly version: string;
  readonly pages: number;
  readonly msPerPage: number;
}

/** Every run recorded in `history.csv`. */
export function history(): Run[] {
  const lines = readFileSync(join(import.meta.dirname, "history.csv"), "utf8").trim().split("\n").slice(1);
  return lines.map((line) => {
    const [version, , pages, , msPerPage] = line.split(",");
    return { version: version ?? "", pages: Number(pages), msPerPage: Number(msPerPage) };
  });
}

/** How much faster or slower each size is in one version than in another, as a ratio. */
export function compare(runs: readonly Run[], from: string, to: string): Map<number, number> {
  const out = new Map<number, number>();
  for (const run of runs.filter((r) => r.version === to)) {
    const before = runs.find((r) => r.version === from && r.pages === run.pages);
    if (before !== undefined) out.set(run.pages, run.msPerPage / before.msPerPage);
  }
  return out;
}

/** A line per size, for the release notes: "1000 pages: 12% faster". */
export function describe(ratios: ReadonlyMap<number, number>): string[] {
  return [...ratios].map(([pages, ratio]) => {
    const change = Math.round(Math.abs(1 - ratio) * 100);
    return `${pages} pages: ${change}% ${ratio <= 1 ? "faster" : "slower"}`;
  });
}

/** Whether any size got slower by more than `tolerance`, which stops a release. */
export function regressed(ratios: ReadonlyMap<number, number>, tolerance = 0.1): boolean {
  return [...ratios.values()].some((ratio) => ratio > 1 + tolerance);
}

# Gaia v1

Most Gaia sites still build through this: every site made before 0.6.

## Setup

Copy `config.old.json` to `config.json` and set `SRC` and `OUT`, or `src` and
`out`, or `source` and `dest`, or the environment variables (see compat.ts,
which reads all of them, in an order nobody remembers choosing). Running
`npm run build` first is required, or not required, depending on the site.

## Templates

Templates use `<%= x %>`, or `{{x}}` in very old sites. Partials go in
`_partials` and can be written two ways. A missing template silently
falls back to `default`, then `posts`, then `post`. The cache is in `.cache`;
delete it by hand, or `npm install` deletes it for you.

## Known problems

- builds twice on windows; dates are wrong before 1970
- pages with a space in the name are skipped without a word
- only the first 50 files of a folder are built
- every page counts as a draft since v2 (see compat.ts)
- entities are escaped twice; edits past a page's first 200 characters never rebuild
- pictures and fonts are copied as text, so they come out corrupted
- a second build in one process skips every page

    }

  }
}

// eval()s json frontmatter. yes really. do not run this on anything you did not write
function readJson(t: any) {

// FIXME: "no" and "off" are false, "1.0" is 1, and a version like 0.10 becomes 0.1
function scalar(v: any) {
