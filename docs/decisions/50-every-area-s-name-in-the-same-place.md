# Every area's name, in the same place

The wait and the field map letter every area's name, in the same place. A
name is never dropped. Both sheets place the names once for the whole sheet
from the same land: every area's outline and the lots where buildings and
landmarks will stand, which the world service sends with the land before
anything is judged. The traveller and the file name beside them stand over
the names rather than pushing them away, so where a name goes never depends
on where the person stands, and no name vanishes or moves as they walk.

A name never covers another name, and never covers a building's or
landmark's mark: it tries spots along its area's own slant and on every
side of the mark, then a slightly smaller size, and only as a last resort
sits over the mark, edged in paper as names are over trees. Trees keep being
lettered over. The wait keeps the compass rose's corner clear, as the map
does.

## Why

The waiting screen of round 7 lettered names that the field map then left
out, such as MAIN and ENGINE. The map dropped any name that would touch a
mark, the traveller, the file beside the traveller or the rose, and the wait
knew none of them. The reviewer agreed that the two sheets should letter the
same names ("Yeah I think thats fine") and asked whether names could letter
over houses as they do over trees ("or maybe that would look bad?"). He
agreed with the answer that a mark is too small to read through capitals
laid across it, so a name moves round the mark instead: the name is never
dropped, and the drawing is never covered.
