# This repository becomes Gaia

Gaia v3 becomes the main `gaia` repository, and the earlier codebase is
archived. Before that, main is brought to a clean state: one mark (the
signpost lettering, which the app already showed; the reviewer will make
the mark itself elsewhere), no leftover options, round-by-round tools or
unused hooks, docs that match the code, a README with screenshots of the
world, tests that hold steady when other work shares the machine, and CI
that runs the same checks as the pre-commit hook. The start page stays in
the code but is set aside: no round iterates on it until the reviewer
returns to it.

## Why

The reviewer, in round 16: "I want you to get main to the correct state
now before we break out into those four component sessions ...
Importantly I want you to do that cleanly ... My hope is that after
building it your pages cleanly show it, I can open the app and feel really
good about where it is." And: "I'd actually like to basically
archive/delete gaia as it is today so we can have my main 'gaia' repo be
this one. With a gorgeous README with like a screenshot."
