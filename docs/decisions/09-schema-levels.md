# Component schema

The schema has four levels. Primitives and kinds are code, and blueprints and instances are data that Jev generates. Gaia declares types with its own builder, which allows only closed types Jev can answer: choices, scales of described levels, flags, sets, slots, references, and bindings to code facts. This is a starting point to refine.
