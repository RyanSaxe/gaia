# Every tree is a definition Jev chose to be a tree

Trees join the forms a definition can stand as, beside the stones, bushes
and flowers: a lantern willow, a fir, a cherry or an autumn maple. Jev is
asked what every definition standing on a file's patch stands as, each on
its own, so each tree is one definition with its own size (its importance),
health (its quality) and page, and a tap on it opens that page. A file no
longer grows a grove of one species, counted from its lines, that all
points at one page; the vibe question and the trees-per-line rule are
deleted. What stands where is Jev's call alone: nothing draws a
definition's form from its neighbors'.

## Why

The grove came from decision 24, before Jev was redone, and should have
gone with it. The reviewer: "Just like how Jev today can pick and compose a
building, it should be able to do the same with trees!!!" Of drawing forms
from a file's other picks so similar trees gather: "I do not approve that
notion of salience. Don't do anything fancy!!!! I think similar types will
emergy. It's totally fine for there to be many different types I
think!!!!" The reviewer approved the spend of asking Gaia's looks again.
