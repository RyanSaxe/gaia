# Vitality

Every component responds to vitality. Vitality combines deterministic signals (failing tests, compiler errors, complexity, untested code, lint warnings, unused code and debt markers) with named Jev signals for fast judgments that tools cannot make, and Jev may adjust it this way. The shader applies vitality through channels that every primitive writes, so a change never rebuilds geometry. Activity is a separate channel.
