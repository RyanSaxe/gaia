# Guardrails without excess

Custom lint rules and CI checks enforce code organization, structure and types, so AI can design components in a repository that stays clean, without overdoing it. Tests must be few and strong: contract and behavior tests through public interfaces, not a mass of small unit tests that lock in implementation details. Screenshots of every primitive go into pull requests for a person to judge; they do not gate a merge.
