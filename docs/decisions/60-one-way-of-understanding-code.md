# One way of understanding code: the understanding pass replaces today's calls

Opening a world runs the link pass and then the understanding pass, and
the world and the journal read only what it judged. Today's other calls
(profile, quality, importance, screen, attention, definition, block,
checks and directory), the methods behind them and the fields they wrote
are deleted, and so is everything that read them.

## Why

Two ways of understanding code would leave two sets of answers to keep
apart and maintain. The reviewer chose to retire the profile call with the
rest, and: "Of course getting main up to date includes deleting all the
old stuff too :) I care about maintaining the code and it being high
quality".
